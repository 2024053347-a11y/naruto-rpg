# v3.0.0 Release Notes

## 忍者手记 v3.0.0 — 火影忍者 AI 文字跑团

> v3 是一次全面重构，覆盖剧情数据库、忍术数据库、AI 叙事管道、变量系统、开局生成、战斗结算、记忆连续性和图片工作室。

## 核心升级

### 完整正史运行时

重建 K001-K086 项目时间线，覆盖四个时代：

| 时代 | 范围 | 内容 |
|------|------|------|
| HIST | K001-K051 | 历史奠基 |
| P1 | 波之国 → 纲手搜索 | 疾风传前 |
| P2 | 晓 → 辉夜 | 疾风传 |
| BOR | 木叶新生代 | 博人传 |

- 385 个剧情日、786 个场景、2894 个原子事件
- 20 个时间线分片、86 份年份状态文件
- 28 个漫画篇章摘要 (4226 个剧情节拍)
- AI 只读取当前可见证据，未来剧情被严格隔离
- 玩家改变原作事件后，时间线会记录分支结果

### 741 条正史忍术数据库

覆盖 NARUTO 漫画第 1-700 话全部已知忍术：

- **统一字段**: 术名(正/繁)、别名、等级(D/C/B/A/S)、类型(忍术/幻术/体术/支援)、属性(火/风/雷/土/水/阴/阳/阴阳)、查克拉消耗、威力值、使用条件、限制、克制、角色技能映射
- **20+ 分类分片**: 核心忍术、基础忍术、火遁、水遁、雷遁、风遁、土遁、瞳术、幻术、体术、医疗忍术、封印术、仙术、傀儡术、通灵术、时空忍术等
- **五行相克**: 火→风→雷→土→水→火
- **等级体系**: D(入门)→C(下忍)→B(中忍)→A(上忍)→S(禁术/影级)
- **正史保护**: 正史忍术数值被锁定，AI 不可随意修改

### AI 叙事与变量系统

- 证据链叙事管道：严格单次调用/增强模式、可见推演、二次变量自检、可选正文复检
- 二次变量更新器：强制将思维链中声明的新任务/新人物/事件落成结构标签
- 开局契约重做：支持自定义家族、血继、天赋、忍术、属性、关系和时代日期
- 血继-家族自动匹配：冰遁→水无月/雾隐，写轮眼→宇智波/木叶，白眼→日向/木叶

### 人物关系面板

- 三维关系：好感度、信任度、尊重度动态变化
- 情感星图：多环分层可视化
- NPC 战斗卡：按忍阶统一平衡
- 人物档案：绝密情报档案卡片设计

### 战斗与记忆

- 统一战斗资源模型：查克拉、精神力、体力、生命值
- 忍术消耗按数据库记录执行且只扣除一次
- 记忆系统：阶段摘要、深度整合、NPC 独立摘要、分支隔离

### 部署与平台

- Windows 原生部署器 (`deploy.ps1`)
- Linux/Mac 部署脚本 (`deploy-v3.sh`) [新增]
- 版本信息生成工具 (`scripts/generate-version.mjs`) [新增]
- 图片工作室：支持 OpenAI 兼容、A1111/Forge、ComfyUI

## 修复列表

- 修复开局天赋/血继无法写入问题
- 修复AI更新成功但面板仍显示普通血脉问题
- 修复二次变量模型思维链显示异常
- 修复任务名称生成但显示未知任务
- 修复人物属性生成异常
- 修复忍术未绑定人物的问题
- 修复人物关系面板交互异常
- 修复开局变量未初始化问题

## 兼容性

- 旧存档可以继续使用，加载时自动迁移
- 旧变量预设会自动升级内置规则并保留自定义内容

## 部署

```bash
# 完整部署
bash deploy-v3.sh

# 仅构建 (不连接服务器)
bash deploy-v3.sh --dry-run

# 跳过构建 (仅上传)
bash deploy-v3.sh --skip-build

# Windows
.\部署正式站.bat
```

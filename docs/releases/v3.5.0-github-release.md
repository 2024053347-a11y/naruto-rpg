# v3.5.0 Release Notes

## 忍者手记 v3.5.0 - 灵希 Agent 与可靠叙事工作流

v3.5 将灵希从普通对话助手扩展为能够理解并操作项目的 Agent，同时重做音乐播放、剧情方向与 Agent 正文定稿流程。所有写操作继续受状态绑定、风险分级和可审计确认保护。

## 核心升级

### 灵希成为项目级 Agent

- 可检索项目正史、忍术数据库、世界书、当前存档、任务、关系、战斗、时间线、云存档和图片图库
- 编写剧情、开局或世界书前必须先完成相关项目检索，当前分支和已发生事实优先于预训练知识
- 可协助设置、变量修复、开局、人设、世界书、剧情方向、装备、物品、任务、普通行动、战斗动作、时间线、云存档、图片生成与图库管理
- 少量可逆设置在后台完成；删除、覆盖、剧情推进、开局初始化、云存档和外部生图必须展示精确影响并点击确认
- API 密钥、NPC 私密状态和内部 Agent 记忆不会进入模型上下文或灵希会话存储

### 更可控的对话界面

- 新增“新开对话”，主动释放旧上下文并清除待处理提案
- 模型上下文按最近消息数与字符数双重限制，长时间使用不会无限增长
- 宠物与桌面对话框可独立拖动、限制在视口内并恢复保存位置
- 确认操作不再要求输入 `yes`；聊天中的“同意”也不能伪造授权

### 音乐播放重做

- 仅保留腾讯音乐目录，删除无效的酷我渠道
- 所有播放地址通过本站 HTTPS 同源代理，避免 Mixed Content 和第三方存储限制
- 播放前验证 HTTP Range、响应大小和音频文件头；不可播放时先换同歌版本，再自动换歌
- 灵希打开歌曲后自动显示默认缩小的悬浮播放器，支持拖动、展开、关闭、上一首、播放/暂停和下一首
- 音乐操作全程后台运行，不再自动打开设置面板

### Agent 正文定稿流程

新版高质量模式在终审前只处理规划材料：

1. 生成场景节拍与角色决定
2. 生成结构化详细写作大纲
3. 执行玩家主权、角色来源、连续性和可检索正史审查
4. 终审通过后一次生成最终正文
5. 独立完成变量、记忆与连续性结算

新增阶段缓存、失败续跑和工具结果预算。严格单模型模式也明确隔离推理、正文与机器标签，并固定唯一 `<state_update>` 格式，减少偶发漏标签造成的回合中止。

### 剧情方向与时间线

- 可按分支保存目标、禁区、节奏、羁绊、伏笔和条件分支
- 方向调整会使旧规划失效，下一轮重新规划，不直接替玩家决定行动
- 时间线跳转、逆转、重推衍、分支切换、主线升格和 IF 分支删除均绑定真实节点与影响范围
- 提案过期、分支变化或并发写入时会在提交前中止；失败回滚不会覆盖同时发生的新提交

### 图片、设置与游戏操作

- 灵希可读取脱敏后的生图配置并发起回合插图或人物肖像提案
- 可选择、解绑、保护、删除图片版本，取消或重试生成任务
- 装备、物品、任务和战斗操作复用现有领域系统，保证属性、数量、奖励、统计和时间线记录一致
- 服务端 AI 代理支持有预算的上游 429 自动重试，Service Worker 与测试站缓存策略进一步收紧

## 安全与兼容性

- 现有本地存档、云存档、世界书、自定义预设和图片资产继续兼容，无需重新开档
- 所有高风险操作仍需独立确认，聊天文本不能批准写入
- 音乐只保留腾讯目录；旧酷我来源不再解析

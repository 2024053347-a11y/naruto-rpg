# 忍者手记 v3.5.0 更新公告

正式站：https://www.qiwu.asia/

## 灵希全面升级

- 灵希现在可以检索正史、忍术、世界书和当前存档，再协助编写剧情、开局与设定。
- 可处理设置、变量、装备、任务、战斗、时间线、云存档、图片生成和音乐等项目操作。
- 新增“新开对话”和上下文上限；宠物与桌面对话框均可拖动并保存位置。
- 少量可逆设置可后台完成；删除、覆盖、剧情推进、云存档和生图仍会展示影响并要求点击确认，不再输入 `yes`。

## 音乐播放器重做

- 删除酷我渠道，仅保留腾讯音乐目录。
- 音频经本站 HTTPS 代理并在播放前检查；当前版本不可播时会自动换版本，再尝试换歌。
- 灵希打开歌曲后会自动显示默认缩小的可拖动悬浮播放器，不再弹出设置界面。

## 剧情生成更稳定

- Agent 模式改为“场景节拍 → 详细写作大纲 → 多重终审 → 正文定稿 → 连续性结算”。
- 终审前不生成正文，并新增正史、世界书、时间、记忆与角色来源检查。
- 严格单模型模式强化 `<state_update>` 固定格式和输出顺序，降低偶发漏标签导致的回合中止。
- 支持按分支设置未来剧情方向、禁区、节奏、羁绊、伏笔和条件分支。

## 其他改进

- 灵希可调用已配置的图片 API 生成回合插图或人物肖像，并管理图片版本与任务。
- 时间线跳转、逆转、重推衍、分支升格/删除加入精确影响确认与并发保护。
- AI 代理新增 429 自动重试，Service Worker 和代码缓存策略进一步修复。
- 旧存档、云存档、世界书、自定义预设和图片资产继续兼容，无需重新开档。

版本：`v3.5.0`

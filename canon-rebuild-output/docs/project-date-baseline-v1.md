# 项目日期基准 project_dates_v1

以下日期是游戏运行使用的正式基准日。`allocated` 表示项目合理推定，不表示漫画明确写出该日。

| 日期 | 基准事件 | 分配理由 |
|---|---|---|
| K051-10-10 | 鸣人出生、九尾之乱 | 10月10日来自生日资料，年份来自世界书 |
| K051-10-11 | 三代火影复任 | 灾难次日开始临时执政与重建最合理 |
| K059-06-15 | 宇智波灭族 | 位于世界书K059；安排在佐助当年生日前，使年龄关系更自然 |
| K064-01-01 | 鸣人毕业 | 冻结为第一部项目元日，便于后续相对日期计算 |
| K064-01-03 | 第七班编成 | 毕业后的第一个正常分班日 |
| K064-01-04 | 铃铛测试 | 分班次日进行生存演习 |
| K064-01-15 | 波之国任务开始 | 给第七班预留约十日D级任务磨合期 |
| K064-01-28 | 波之国决战 | 包含旅途、第一次交战与约一周爬树训练 |
| K064-03-01 | 中忍考试开始 | 波之国后预留一个月执行任务和报名 |
| K064-03-06 | 死亡森林结束 | 使用第二场考试五日上限 |
| K064-04-06 | 正式赛、木叶崩溃 | 从预选阶段结束顺延一个30日项目月 |
| K064-04-20 | 纲手就任五代火影 | 为葬礼、寻找纲手和返村预留两周 |
| K064-06-01 | 佐助离开木叶 | 为纲手执政、鼬归村影响和佐助恶化预留约六周 |
| K064-06-03 | 终结之谷第一次决战 | 按追击任务持续约两日分配 |
| K067-01-01 | 鸣人修行归来 | 与K064第一部元日构成约三年阶段边界 |
| K067-01-12 | 一尾被晓抽离 | 鸣人归来后紧接风影夺还篇 |
| K067-08-15 | 佩恩摧毁木叶 | 为天地桥、飞段角都、鼬决战和自来也调查预留时间 |
| K068-01-01 | 第四次忍界大战开战 | 冻结为K068战争阶段起点 |
| K068-01-03 | 第四次忍界大战结束 | 原著大战主体集中在连续数日内 |
| K068-01-04 | 终末之谷最终决战 | 辉夜被封印后，鸣人与佐助的决战持续至夜间 |
| K068-01-05 | 无限月读解除 | 原文明确两人在决战次日早晨醒来，随后解除无限月读 |
| K068-01-12 | 战争葬礼与佐助羁押 | 为伤员返村、遗体安置和战争善后预留时间 |
| K068-02-01 | 卡卡西就任六代火影 | 属于战后重建，不与大战当天合并 |
| K068-02-02 | 佐助获赦并离村赎罪 | 发生在审查与治疗安排之后 |

日期调整只能发布新的日期版本；事件稳定ID不得改变或复用。

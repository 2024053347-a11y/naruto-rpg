# 全年代时间线范围与裁定

## 当前覆盖

- K001—K086每年均有年度状态文件。
- 出生注册表包含140人；年度文件同时给出年初年龄、生日和生日后年龄。
- 《NARUTO》漫画第1—699章按19个主要篇章拆分剧情节拍，另含第700章战后边界。
- 《NARUTO》外传、《BORUTO》与《BORUTO: TWO BLUE VORTEX》使用 `boruto_manga`，与 `manga_canon` 分离。

## 用户纪年资料的处理

用户提供的出生年月和年份事件被视为项目纪年候选。漫画没有给出绝对年份的内容使用
`project_allocation`，不宣称原著明示。下列民间扩写不作为原著事实：

- 角都因“其他村两只尾兽、泷隐只有最弱一只”而刺杀柱间。
- 尾兽交易资金直接造就火之国经济优势的完整因果链。
- 没有漫画或公式书出处的战争精确年份、阵亡名单和机构人数。

## 年龄算法

项目没有0年。年度文件采用：

- 出生当年年初尚未出生：`age_at_year_start = null`
- 其余年份年初年龄：`当前年 - 出生年 - 1`
- 当年生日后：`当前年 - 出生年`
- 出生当年生日后年龄为0。

人物在死亡年份标记 `dies_this_year`，死亡后的年度不再进入在世年龄清单。

## 审核状态

篇章页的详细Summary可能混入动画改编补充，自动记录全部保持 `draft`。只有逐章审核并改为
`qa.status = approved` 的事件才会进入正式运行时索引。
